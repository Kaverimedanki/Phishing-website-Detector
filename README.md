# Phishing Website Detector

A machine learning based web application for detecting potentially suspicious phishing URLs.

## Features

- URL-based phishing detection
- Machine Learning classification
- Suspicious URL pattern detection
- Flask web application
- Safe / Suspicious result display

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- Joblib
- HTML
- CSS

## Dataset

UCI Phishing Websites Dataset with 11,055 website records.
